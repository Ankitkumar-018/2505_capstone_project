# AI/ML Capstone Projects

This repository contains 4 ready-to-assign capstone project briefs for the AIML program. Each is a
complete, end-to-end data project (SQL → Python/Pandas → Seaborn EDA → ML modeling → business
insight → GitHub submission), sized for a 10-day individual sprint.

## Start Here

Read [capstones/00_common_guidelines.md](capstones/00_common_guidelines.md) first — it covers the
shared rules, GitHub workflow, submission checklist, and grading criteria that apply to every
project below. Then open the specific project file assigned to you.

## Projects

| # | Project | Domain | ML Task |
|---|---|---|---|
| 1 | [House Price Prediction](capstones/01_house_price_prediction.md) | Real Estate | Regression |
| 2 | [Employee Attrition Prediction](capstones/02_employee_attrition_prediction.md) | HR Analytics | Classification |
| 3 | [Superstore Sales & Profit Analytics](capstones/03_superstore_sales_profit_analytics.md) | Retail | Regression |
| 4 | [Loan Default Prediction](capstones/04_loan_default_prediction.md) | Banking / Fintech | Classification |

## Difficulty

Easy–Intermediate. Each project uses one clean public dataset, 5 SQL questions (including one
subquery), 6–7 Seaborn charts, one engineered feature, and 3 ML models (baseline + Decision Tree +
Random Forest) — beginner-friendly but with enough rigor for a real portfolio piece.

## Mode

Individual. Every student submits their own repository.

## Submission

Every project is submitted as a public GitHub repository + demo video, per the checklist in
[00_common_guidelines.md](capstones/00_common_guidelines.md#12-submission-checklist).
